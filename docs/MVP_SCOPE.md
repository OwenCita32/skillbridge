# MVP Scope and Priorities

## 1. Objective
Deliver a working, coherent demo of the core SkillBridge value within the available sprint. Prefer a complete end-to-end path over many disconnected screens.

## 2. Must-have
1. Authentication or a clearly controlled demo-user flow.
2. Career catalog/selection.
3. Skill assessment with a documented scale.
4. Backend skill-gap calculation.
5. Roadmap generation or a deterministic fallback roadmap.
6. Curated learning resources.
7. Progress update and persistence.

## 3. Should-have
- Dashboard summarizing target career and next action.
- Assessment result detail.
- Resource filters or resource detail.
- Clear AI-generated content labeling.

## 4. Could-have
- Portfolio/evidence.
- Job application tracker.
- Notifications/reminders.
- Advanced analytics.
- Admin content management.

## 5. Out of scope unless explicitly approved
- Automatic job applications.
- Scraping job sites.
- Social networking/feed.
- Course marketplace/payment.
- Claims of certified skill verification.
- Complex recommendation algorithms without evaluation data.

## 6. Sprint rule
If time is limited, cut optional features before compromising authentication, data integrity, core flow, security, or UI quality.

## 7. Demo acceptance
A user can select a career, complete an assessment, see understandable skill gaps, obtain a roadmap grounded in available resources, and update progress without crashes or fabricated resource links.
